# The Drowned Measure — Formatting Rule

- In chapter prose, bold every occurrence of every tracked target word with standard Markdown: `**word**`.
- Bold both first encounters and recycled encounters, preserving the inflected form used in the sentence.
- In the Word-Hoard, bold target occurrences in chapter quotations and fresh examples.
- Keep Ledger words unformatted so the JSON remains valid for SRS import.
